# Themes

Launchpad has three themes. Each person picks their own; the choice does not
change what other people see.

- **Default**: the standard look. Compact rows and a neutral palette. This is
  the theme you have until you choose another. (The API and the stored value
  call it `linear`.)
- **Paper**: warm paper and ink. Serif headings (Fraunces) over a sans text
  face (Source Sans 3), airy rows, thin rules and no shadows.
- **Terminal**: a console. One monospace face (JetBrains Mono), square corners,
  dense rows. A state is a word in brackets, for example `[WIP ]` or `[DONE]`,
  and switches show as `[x]` and `[ ]`.

## Choose a theme

1. Open **Settings**, then **Appearance** (in the Account group).
2. Under **Theme**, select Default, Paper or Terminal. Each choice shows a small
   preview. The app changes at once.

The server keeps your theme. It follows you to every browser, device and
organisation where you log in. If the save fails, the app shows the previous
theme again and tells you.

## Light and dark

Every theme has a light and a dark variant. Under **Light or dark** on the same
page, select **Match the system**, **Light** or **Dark**. The user menu
("Mode") and the command palette ("Light mode", "Dark mode", "Match system
mode") have the same choice. This choice is kept in the browser only, as
before. The command palette also has "Theme: Default", "Theme: Paper" and
"Theme: Terminal".

## Notes

- The fonts come from the Launchpad server itself. A browser loads a theme's
  fonts only when the theme is in use (and on the Appearance page, for the
  previews).
- When you sign out, the browser forgets your theme: the login page is Default.
- Other open tabs of the same browser follow a change at once.
- Agent users have no theme.
- Every theme and variant meets WCAG AA contrast: 4.5:1 for text, 3:1 for
  controls and focus rings.
